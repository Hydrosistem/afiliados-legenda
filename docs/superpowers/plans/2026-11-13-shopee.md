# Links da Shopee: plano

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `info` aceita links da Shopee e devolve título, preço, preço antigo e imagem pela Affiliate Open API, com a credencial do vendedor.

**Architecture:**
- Funções puras em `src/parse.gs`: hosts da Shopee, extração dos IDs e cálculo do preço antigo.
- Novo `src/shopee.gs`, com:
  - resolução do link curto;
  - assinatura e consulta à API;
  - cota de 100 consultas por cliente por dia.
- `buscarInfo_` desvia os links da Shopee para `buscarShopee_`.
- A tela só ganha mensagens novas.

**Tech Stack:** Apps Script, `node --test` com os fakes de `test/helpers/gas-stubs.js`.

**Spec:** `docs/superpowers/specs/2026-11-13-shopee-design.md`

## Global Constraints
- **Credencial:** propriedades `SHOPEE_APP_ID` e `SHOPEE_SECRET`. Nunca no código.
- **API:**
  - Endpoint: `https://open-api.affiliate.shopee.com.br/graphql`.
  - Header: `Authorization: SHA256 Credential=<appId>, Timestamp=<segundos>, Signature=<sha256 hex minúsculo de appId+timestamp+corpo+secret>`.
- **Consulta:** `productOfferV2(itemId: <n>, shopId: <n>, limit: 1)` pedindo os campos `productName imageUrl priceMin priceMax priceDiscountRate`.
- **Links:** nunca chamar `generateShortLink`, e a legenda continua com o link colado pelo cliente.
- **Cota:** `COTA_SHOPEE_DIA_ = 100` por e-mail por dia, contada só quando a API é chamada. Acerto em cache não conta.
- **Erros novos:**
  - `shopee`: falha da API, credencial ausente ou produto não encontrado.
  - `cota`: cota do cliente ou código 10030 da API.
- **Imagem:** `susercontent.com` entra em `HOSTS_IMAGEM_`.

## Review Focus
- Assinatura calculada sobre exatamente o mesmo texto enviado no corpo.
- Link curto que não chega a uma URL com IDs devolve `link_curto`, para a tela pedir o link do produto.
- Redirecionamento para fora da Shopee é recusado com `host`.
- Cache por URL, para que a mesma consulta repetida não gaste cota nem chame a API.
- Credencial ausente devolve `shopee`, nunca uma exceção.
